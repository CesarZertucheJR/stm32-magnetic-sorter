# STM32 Magnetic Sorting System

Automated material classification and sorting system programmed in ARM Assembly on an STM32F4 microcontroller. The system detects incoming objects using an IR sensor, classifies them as magnetic or non-magnetic using a Hall-effect sensor, and actuates a servo motor to route each object to the correct output bin.

---

## Hardware

| Component | Pin | Function |
|---|---|---|
| IR sensor (active-LOW) | PA0 | Detects object presence — goes LOW when object is on platform |
| Hall-effect sensor | PA1 | HIGH when magnet detected |
| IR detection LED | PA5 | Lights when object is seen |
| Magnet detection LED | PA6 | Lights when magnet is classified |
| Servo motor | PA8 | PWM output — controls sorting gate angle |

---

## How It Works

1. **Idle** — servo holds at 90° (center). Both LEDs off. System polls PA0 continuously.
2. **Object detected** — IR sensor pulls PA0 LOW. IR LED (PA5) turns on immediately as user feedback. System waits 3 seconds for the user to clear their hand.
3. **Hall sensor settle** — additional 1 second delay for the Hall sensor to stabilize on the stationary object.
4. **Classification** — PA1 is read:
   - **HIGH (magnet)** — Hall LED (PA6) turns on, servo tilts to 180°, holds 5 seconds while object slides off
   - **LOW (no magnet)** — servo tilts to 0°, holds 5 seconds while object slides off
5. **Reset** — servo returns to 90°, both LEDs off, 2.5 second cooldown to prevent re-triggering, then back to idle

---

## Servo Timing

No hardware timers are used. PWM is generated by software bit-banging on PA8 using counted delay loops:

| Constant | Loop Count | Angle |
|---|---|---|
| `SERVO_0DEG` | 1000 | 0° |
| `SERVO_90DEG` | 6000 | 90° (center) |
| `SERVO_180DEG` | 10000 | 180° |
| `SERVO_PERIOD` | 80000 | Full 20ms period |

Each call to `SERVO_PULSE` generates one complete 20ms PWM cycle. Delays are measured in pulse counts — 50 pulses = ~1 second.

## Code Structure

```
stm32-magnetic-sorter/
├── README.md
└── src/
    └── main.s
```

**main.s** is organized into the following labeled sections:

| Label | Description |
|---|---|
| `__main` | Clock and GPIO initialization, startup servo centering |
| `WAIT_FOR_OBJECT` | Main polling loop — monitors PA0 for object presence |
| `OBJECT_DETECTED` | Turns on IR LED, waits for hand removal and Hall sensor settle |
| `HALL_ON` | Magnet path — drives servo to 180°, holds 5 seconds |
| `HALL_OFF` | Non-magnet path — drives servo to 0°, holds 5 seconds |
| `RESET_AND_WAIT` | Returns to center, clears LEDs, cooldown, loops back |
| `SERVO_PULSE` | Subroutine — generates one 20ms PWM pulse on PA8 |

---

## GPIO Configuration

Configured via direct register writes to `GPIOA_MODER` (no HAL library used):

- PA0, PA1 — input mode (`00`)
- PA5, PA6, PA8 — output mode (`01`)
- Clock enabled via `RCC_AHB1ENR` before any GPIO access

---

## Tools & Environment

- **IDE:** STM32CubeIDE
- **Language:** ARM Assembly (ARMv7-M instruction set)
- **Board:** STM32 NUCLEO-F401RE (ARM Cortex-M4, 84 MHz)
- **Programmer:** ST-LINK/V2 (on-board)
